# Face Recognition-Based Attendance System using Raspberry Pi

- Traditional attendance systems rely on manual processes that are time-consuming and 
prone to errors.
- This project introduces an automated Face Recognition-Based Attendance 
System using a Raspberry Pi 4 Model B, Pi Camera, and OpenCV. The system captures and 
verifies student faces in real-time, marking attendance securely while preventing duplicates.

# Key features include: 
- • Modular design (Registration, Attendance, Training, Face Detection, Configuration). 
- • Course-wise validation to ensure only enrolled students are marked present. 
- • Hardware efficiency with Raspberry Pi, LCD feedback, and push-button control. 
- • Real-time operation using Haar Cascades and LBPH (Local Binary Patterns 
Histograms) for face recognition. 

The system achieved 90% accuracy under controlled lighting and was tested successfully in a 
classroom environment. Future enhancements include cloud integration and mobile app 
support.
